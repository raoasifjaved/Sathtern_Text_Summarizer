# START HERE — Briefly AI

1. Open PowerShell in this folder.
2. Create and activate `.venv`.
3. Run `pip install -r requirements.txt`.
4. Copy `.env.example` to `.env`.
5. Leave `GROQ_API_KEY` blank for Local NLP mode first.
6. Run `python run_checks.py`.
7. Run `streamlit run app.py`.
8. Paste a 250–500 word article or use `samples/sample_long_text.txt`.
9. Generate a Balanced summary.
10. Compare original and summary, check compression, and export a report.
11. Add your Groq key and test AI mode.
